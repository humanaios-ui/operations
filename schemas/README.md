# System stance schema

`system_stance_v1.schema.json` defines an evidence-linked assessment of possible
opportunities, uncertainty, and outstanding pre-action checks.

A stance is advisory only. It does not grant permission, approve a proposal, or
authorize consequential action; the applicable human and governance processes
retain all authority. In particular, `ACT` is only an advisory disposition and
is valid only when every pre-action requirement is verified.

The portable validation examples live in
`../fixtures/system_stance_v1/`. They include a valid record and invalid
mutation cases for downstream schema consumers.
