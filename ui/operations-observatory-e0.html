Interpretation & limits

What the signal means

  • Updated: Each record is counted once at its latest GitHub update time, not once per comment or commit.
  • Kinetics: Bars are 28 rolling 24-hour last-update buckets; seven-day comparisons show touched items, not event throughput.
  • Coverage: Public API pages are capped. Partial fetches and malformed records require visible caveats; totals may be lower bounds.
  • Authority: Reading data never admits a PR, assigns a task, approves a claim, or changes an issue.
  • Privacy: No keys, cookies, private data imports, analytics beacons, or browser storage. Public GitHub GET only.
  • Cross-system: Project Desk, authenticated INTENT-OS, and real-world outcome evidence are not connected in E0.
