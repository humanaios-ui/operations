# GENESIS_READINESS — Q-WITNESS-COMMONS-ASSURANCE-01 (Phase 0)

## Governing question

**What must be demonstrated before the first official standing human Sigil may be created?**

## Minimum readiness criteria

1. **Contract integrity**
   - Participation Contract and Witness State schemas are versioned, reviewable, and test-validated.
   - Participation metadata cannot self-grant effective governance authority.

2. **Authority separation**
   - Effective authority resolves from an independent governance source, not participation/session payloads.
   - "Witness is not authority" is encoded in contracts and test gates.

3. **Revocation enforceability**
   - Revocation events carry explicit `effective_after_event_seq` boundaries.
   - Post-revocation collection/use paths are blocked and explainable.

4. **Evidence reconstruction path**
   - "Why are you...?" responses are reconstructable from durable records:
     declaration → acknowledgement → consent receipt → event → derivation → decision → policy.

5. **Omission semantics**
   - Omission classes are first-class metadata and reflected in downstream reasoning.

6. **Scope discipline**
   - Phase 0 output remains inventory/audit/specification only.
   - No implied authorization for enrollment, training, deployment, settlement, or authority expansion.

## Current phase verdict

This file records **readiness criteria only**. It does **not** certify readiness or authorize Genesis execution.
