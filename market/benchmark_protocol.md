## 1. Comparative ladder

```text
BASE AGENT
        vs
OBSERVABILITY-INSTRUMENTED AGENT
        vs
HUMANAIOS-GOVERNED AGENT
```

The benchmark asks whether an independent observer can determine:

1. what happened,
2. why it happened,
3. what evidence supported the action,
4. whether the evidence was independent,
5. what authority allowed it,
6. whether scope was respected,
7. what remained unknown or challenged,
8. what was executed,
9. what consequence occurred,
10. whether the warrant changed afterward.

## 2. Benchmark phases

### Phase A — Desk benchmark (completed)

- **Run ID:** `BMK-0001`
- **Date:** 2026-09-24

### Phase B — Controlled fixture benchmark (required)

- Create one consequential but non-sensitive fixture action.
- Run the same fixture through:
  1. a base agent log,
  2. a trace/observability stack,
  3. a HumanAIOS-governed representation.
- Blind at least one reviewer to system condition.
- Record reconstruction quality, time, uncertainty capture, and authority-boundary accuracy.

### Phase C — External-user utility benchmark (required for consequential-action claims)

- Minimum one participant from an external stakeholder class.
- Pre-register success/failure metrics from `market/actor_map.yaml`.
- The external protocol review logged as `UTILITY-0001` satisfies the track's minimum “external user looked at this and provided actionable signal” requirement.
- Promotion still remains blocked for consequential-action utility claims until an external user completes a task-based benchmark on the comparative ladder above.

## 3. Initial benchmark finding

The completed desk benchmark showed that several mature products already claim strong coverage for observability, governance, monitoring, evaluation, and policy controls. That means HumanAIOS cannot treat category existence as differentiation. The remaining open question is narrower: whether explicit evidence/warrant/authority/receipt structure, disagreement preservation, provenance topology, and public verifiability create measurable user value not already delivered by the strongest comparators.
