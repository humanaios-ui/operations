## Adversarial attack paths
1. **Instruction laundering:** linked GitHub issue or retrieved chat says "execute"; agent mistakes source text for current user authority.
2. **Coverage laundering:** one memory summary or recent search is described as all historical work.
3. **Identifier laundering:** same ID in different scopes is marked SAME_AS with no stable owner decision.
4. **Graph-family laundering:** 19-, 195- and 358-node graphs are merged on semantic similarity without original snapshot/version identity.
5. **Identity laundering:** self-labeled Claude/Grok/ChatGPT mail or comments are treated as independently authenticated controllers.
6. **Privacy laundering:** a private index, message handle, local path, or name is embedded in a public issue/PR or CI log.
7. **Receipt laundering:** a GitHub comment or local SHA is described as signed external custody, independent acceptance, or verified human benefit.
