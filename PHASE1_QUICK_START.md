# Phase 1 Pilot: Quick Start Guide (For Team)

**Start Date:** Aug 8, 2026  
**Duration:** 6 weeks  
**Team Size:** 4-6 people  
**Weekly Hours:** ~12 hours per person (varies by role)

---

## What We're Doing

Building a **fair research task marketplace** where:
- Employers post tasks (writing, analysis, design, validation)
- Workers earn money directly (no extraction, transparent fees)
- We make 5% coordination fee (2% back to workers as bonus)
- We publish everything (Substack monthly transparency reports)

**Goal:** Test if fair orchestration works. Run 20-50 real matches over 6 weeks. Measure satisfaction + completion + repeat rates. Decide: scale Phase 2 or iterate.

## Success Metrics (Sep 12)

**Go to Phase 2 if:**
- Worker satisfaction: 80%+
- Employer satisfaction: 80%+
- Task completion: 95%+
- Worker repeat interest: 50%+
- Employer repeat interest: 50%+

**If 5+ of 5 criteria met:** SCALE to 100-200 matches/month  
**If 3-4 criteria met:** ITERATE (fix top issue, re-pilot)  
**If <3 criteria met:** PIVOT (reassess model)

## Blockers & Escalation

### If X happens → Do Y

- **GitHub org creation fails** → Use temporary repo, escalate to tech support
- **Open Collective signup rejected** → Use empirica-foundation account instead
- **Employer recruitment slow** → Expand to Tier 3 (open-source communities)
- **Worker recruitment slow** → Hire internal team members as test workers
- **Payment processing breaks** → Switch to manual Stripe transfers (temporary)
- **ACAT assessment not validated** → Proceed with manual matching (planned backup)
- **Mesh feedback unclear** → Proceed Week 4 without ACAT, revisit Week 5

**Escalation point:** Operations Lead flags blockers by end of each week. Team resolves async via Slack.
