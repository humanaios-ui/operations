## Purpose

Establish a repeatable, testable playbook for inviting collaborators into HumanAIOS at different commitment levels while maintaining epistemic rigor and mesh discipline.

**Scope:**
- Collaborators new to HumanAIOS or Empirica mesh
- Integration levels: Advisor, Co-investigator, Core team member
- Platforms: Empirica mesh, Direct email, Project-specific engagement
- Validation: Test with internal candidate before real outreach

---

## Collaboration Levels & Engagement Types

| Level | Commitment | Decision Authority | Artifact Access | Mesh Role |
|-------|------------|-------------------|-----------------|----|
| **Advisor** | As-needed (est. 5-10 hrs/mo) | Consultation input (non-binding) | Read-only findings | Peer reviewer |
| **Co-Investigator** | Part-time (est. 10-20 hrs/mo) | Joint decision on scope + methodology | Full project access | Active contributor |
| **Core Team** | Part-time+ (est. 20+ hrs/mo) | Co-decision on direction + goals | Full access + commit rights | Partner/co-PI |

## Onboarding Playbook (By Stage)

### Stage 1: IDENTIFICATION & VETTING (Noetic)

**Goal:** Confirm fit before outreach

**Steps:**
1. [ ] Identify candidate & integration rationale
   - Who? (Name, affiliation, expertise)
   - Why? (What gap do they fill?)
   - What level? (Advisor/Co-I/Core?)
   - Timeline? (When do we need them?)

2. [ ] Vet for mesh-readiness
   - [ ] Do they understand empirica mesh discipline (pull, push, ack, don't drop)?
   - [ ] Do they have epistemic maturity (can work in noetic/praxic phases)?
   - [ ] Any conflicts of interest with HumanAIOS mission?
   - [ ] Availability realistic for the level?

3. [ ] **ECO DECISION GATE #1:** [TBD - Operational or Human-Gated?]
   - [ ] Internal team confirms fit
   - [ ] Governance layer approves outreach

**Artifacts:**
- [ ] Candidate profile (vetting notes)
- [ ] Rationale memo

---

### Stage 2: OUTREACH & PROPOSAL (Praxic)

**Goal:** Invite collaborator with clear expectations

**Steps:**
1. [ ] Prepare collaboration packet
   - [ ] Brief on HumanAIOS mission & current work
   - [ ] Role description + time commitment
   - [ ] Mesh discipline expectations
   - [ ] What success looks like (metrics, deliverables)

2. [ ] Send outreach via preferred channel
   - [ ] Mesh collab (if empirica practitioner): `cortex_collab`
   - [ ] Direct email (if external): structured message with same info
   - [ ] Include: REPLY BY DATE (typically 1-2 weeks)

3. [ ] **ECO DECISION GATE #2 (if needed):** [TBD]
   - [ ] If candidate is cross-org: does coordination need ECO gate?
   - [ ] If candidate is existing mesh: is this "create SER" moment?

**Artifacts:**
- [ ] Outreach email / collab message template
- [ ] Collaboration packet PDF/link
- [ ] Sent email/timestamp log

---

### Stage 3: RESPONSE & CLARIFICATION (Collaborative)

**Goal:** Resolve questions & confirm mutual fit

**Steps:**
1. [ ] Receive response (or follow up if no response by deadline)
   - [ ] Candidate confirms interest
   - [ ] Candidate asks clarifying questions
   - [ ] Candidate declines (gracefully close, document learning)

2. [ ] Synchronous kick-off call (if accepted)
   - [ ] Walthrough of first 30 days
   - [ ] Access setup (mesh, repos, project tools)
   - [ ] First task/project assignment
   - [ ] Communication cadence & escalation path

3. [ ] **ENGAGEMENT CREATION (Operational or Mesh-Coordinated?):** [TBD]
   - [ ] Create empirica engagement record (if applicable)
   - [ ] Set duration (1-6 months typical, renewable)
   - [ ] Define success metrics & review checkpoints

**Artifacts:**
- [ ] Email thread / collab thread
- [ ] Call notes (decisions, task assignments)
- [ ] Engagement record (if applicable)

---

### Stage 4: ACTIVE COLLABORATION (Ongoing)

**Goal:** Maintain productivity, mesh discipline, and mutual learning

**Monthly (or per-task):**
- [ ] Async check-in: project status, blockers, wins
- [ ] Log findings/decisions from their work
- [ ] If cross-practice: ensure mesh discipline (ack proposals, don't drop threads, cite sources)

**Quarterly (for Core team) or After 1st Project:**
- [ ] Structured retro on collaboration
  - [ ] What worked?
  - [ ] What would improve collaboration?
  - [ ] Continue, escalate, or wind down?

**Mesh Discipline:**
- [ ] Collaborator acks completed proposals (completion handshake)
- [ ] Citations flow both ways
- [ ] Mesh collab used for questions/blockers (not direct DMs)

**Artifacts:**
- [ ] Project findings/outcomes
- [ ] Retro notes (if applicable)
- [ ] Mesh messages/collab thread (auto-logged)

---

### Stage 5: TRANSITION / EVALUATION (Noetic + Praxic)

**Goal:** Measure impact, update relationship, or gracefully close

**At 3 months (or project end):**
- [ ] **Impact Assessment:**
  - [ ] Deliverables completed?
  - [ ] Mesh contribution quality?
  - [ ] Would we want to continue?

- [ ] **Collaborator Feedback:**
  - [ ] Were expectations clear?
  - [ ] Did HumanAIOS deliver on our end?
  - [ ] Would they want to continue?

- [ ] **Decision:**
  - [ ] Continue (same level or escalate?)
  - [ ] Wind down (with gratitude + lessons logged)
  - [ ] Escalate to higher commitment level?

**Artifacts:**
- [ ] Impact assessment memo
- [ ] Lessons from collaboration (logged in findings/decisions)
- [ ] Updated engagement record (continued or closed)

## Validation Checklist (Before Real Outreach)

**BEFORE contacting any real candidate, test this playbook:**

- [ ] **Dry-run with internal test:** Walk through Stages 1-2 with Sarah Preseley (confirmed test-candidate)
  - [ ] Does the outreach message make sense?
  - [ ] Are timing/expectations clear?
  - [ ] Do mesh discipline requirements sink in?

- [ ] **Governance verification:** Confirm with David/ECO
  - [ ] Which gates are actually gated? (Don't guess)
  - [ ] What does "approval" look like? (Decision authority, timeline)
  - [ ] Any missing pieces (conflict checks, reference calls, contract review)?

- [ ] **Artifact logging:** Verify we're logging everything correctly
  - [ ] Are findings from collaborators being captured?
  - [ ] Are decision points logged?
  - [ ] Is the engagement record created & tracked?

- [ ] **Mesh discipline test:** Simulate a mesh collab back-and-forth
  - [ ] Does the collab land correctly?
  - [ ] Can candidate reply + thread?
  - [ ] Does the ack handshake work?

- [ ] **No real outreach until:** All checkboxes above are CONFIRMED, not guessed
