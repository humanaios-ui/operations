The reference design is `humanaios-ui/operations` at `4abc5da3fda80b3f33395c2eb0ef6a820e7fcdb4` (Resource Miner `README.md`, `resource_miner/intent_os.py`, `resource_miner/planning.py`). It has not been executed with the real application, CI, or canonical planner. The planning projection uses proposed `public_record` and `evidence_access` taxonomy values; these require review before integration. It does not change existing routing or authority policy.

The module accepts bounded **human-curated, annotated public evidence notes**, checks exact schema, source URL allowlist, dates and digest, rejects conflicting reference identities, deduplicates identical references, retains locators, and exports unretrieved record leads. No network, credentials, external writes, disclosure actions, automatic FOIA or publication. It is not a crawler, source authenticity verifier, natural-language extractor, or evidence of scientific findings. An allowlisted URL and self-supplied checksum are not proof of provenance or truth. The note corpus was manually constructed from public sources on November 25, 2026; it freezes notes, not full original document bytes. References to the final report indicate a requirement, not proof the report has been created or released. No operational military details or personal contacts are needed for this case.

## Comparison design and limits
A: conventional investigator, author-coded retrospective reconstruction from the same notes, credited with all nine visible record references. B: actual offline adapter execution. C: actual adapter plus author-coded Witness-style challenge and planning output. A and C are NOT independently run agent workflows. The notes already contain labeled references, so the exercise is a normalization/replay benchmark rather than a discovery benchmark. All arms receive the same notes and each has 9/9 expected leads under the author-created provisional key; no measured incremental discovery. B avoids making a conflict or exposure judgment; A and C record unresolved/unknown. C provides structured review tasks. There is no unbiased accuracy, time, cost, or causal performance estimate. No records were obtained merely by indexing their references. No result establishes environmental exposure or lack of exposure, unlawful withholding, or safe treatment.
