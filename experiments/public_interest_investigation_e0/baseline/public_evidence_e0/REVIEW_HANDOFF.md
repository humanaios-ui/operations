# Independent evaluator handoff — proposed, not dispatched

Send these instructions and `source_list.txt` (NOT the annotated fixture, author key, or outputs) separately to two independent reviewers, e.g. Claude Code and Grok, or a human environmental records reviewer and a separate software reviewer. Do not share one reviewer's findings with the other until both submit. A model name is not an authenticated evaluator identity. Record evaluator identity, environment/version, timestamps, source availability, exact corpus digest and tool use. No private sources, publication, requests, repository writes, or live agent activation.

## Phase 1: independently derive the reference ledger
Read only the listed public records. Freeze your independently authored findings before seeing the existing package. Identify distinct dated decision/engagement/sampling documents and final-report obligations in the selected permit sections (pp. 2–3, 18, 20), distinguish record reference from retrieval, and include locator, date or unknown, source URL, status, and uncertainty. Record scope exclusions and contradictory claims, without resolving exposure or legality from the permit alone. Produce your own answer key with count and supporting page references; report disagreements, not guessed facts. Record any source that changed or could not be accessed.

## Phase 2: software and method review
After freezing Phase 1, receive the full archive. Verify its manifest. Run the test suite and replay on your own environment; check outputs rather than accepting the author's report. Review exact URL allowlist, JSON size and nesting, untrusted text, duplicate IDs/aliases, caller-controlled digest, source category spoofing, missing record dates, evidence state transitions, and whether the projection could be misread as approval. Plant additional negative cases. Identify failures or absent coverage and propose fixes. Compare your own independently derived ledger with the nine-item author-selected subset and report additions/omissions and scope differences. Do not claim the author-selected subset exhausts the permit.

## Phase 3: prospective comparison design
Freeze a NEW corpus of source text with no preannotated IDs or references, same query and retrieval budget for each arm, no cross-arm leakage, and separate blinded adjudicators. A: conventional investigator. B: implement a permitted ingestion/extraction adapter and run it without investigator/Witness. C: same adapter plus actual investigator and Witness runtime. Record unique correct leads, incorrect/unsupported leads, missed references, duplicate handling, citation quality, time and tool cost. Distinguish referenced, required, retrieved, and independently verified records. Stop if a method cannot run; never substitute a simulation without labeling. Require zero unauthorized actions and no unsupported exposure/legal claims before even considering admission.

## Return format
Evaluator ID and version; corpus and code digests; original source ledger; reproducible commands and raw outputs; added tests; discrepancies; severity and proposed fixes; independently justified PASS/HOLD/FAIL for this narrow prototype. Final independent review status remains pending until actually returned and reconciled by the operator.
