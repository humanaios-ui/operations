Limits, still true: data fictional. The reserve rule holds by construction, so 200/200 reserve kept is a property of the rule, not a finding. Principal string comparison assumes a trusted context and is not authentication. The duplicate fixture uses a prepopulated seen set, not persistent atomic idempotency. Out-of-band mutation is detected after the fact, not prevented. Arm C bundles three changes (consent, reserve, fairness order); `ablation` shows the useful-work cost comes from the reserve floor, consent alone slightly raises useful work, and the more even split comes from the fairness order, not the gate. The communication fixtures are exact-field contract tests, not semantic fact checking; the three media get identical input, so medium effect is not measured. No causal inference or ACAT score. C06: splitting the gated design apart, most of the useful-work cost came from the 25-unit reserve floor (589.22 with reserve alone), not from human consent (613.79 with consent alone); the more even split came from the turn order, not the gate.
