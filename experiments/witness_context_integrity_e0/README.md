The pure offline classifier routes fixture receipts into independent axes: media origin (CAMERA/SYNTHETIC/HYBRID/UNKNOWN/DISPUTED), alteration, event (CORROBORATED/STAGED/UNKNOWN/DISPUTED), interpretation (SUPPORTED/CONTRADICTED/CONTEXT_MISMATCH/UNSUPPORTED/DISPUTED), delivery (LIVE_CAPTURE/REPLAY/UNKNOWN/DISPUTED). These labels scope the stated claim/clip only, not a person, publisher intent, entire video or causal autonomy. Unedited is a fixture assertion, not inferred from no observed edit. Staged may describe a real camera recording. Synthetic can communicate supported facts. Unsupported does not mean false. Conflict holds the relevant axis without manufacturing consensus. No detector-only verdict. Duplicate receipts and same-source reposts do not create independence. Inputs are bounded fixture IDs with exact asset/range/revision/claim binding; unrecognized or mismatched receipts rejected. No source acquisition, network, video decode, graph mutation, provider calls, or release action. All outputs review-only with authority NONE.

## Trust limitations
Registry is an in-memory synthetic oracle, not authentication. FIXTURE_VERIFIED, asset strings and root identifiers are fabricated test data, not validated signatures or independently verified people. The code assumes an externally controlled registry; caller-controlled registry would defeat trust. One provenance root for media/alteration and two roots for event/interpretation/delivery are design choices, not proof of source quality or genuine independence. Conflicting evidence conservatively yields DISPUTED even when one side is below quorum. No semantics, actual live capture verification, detector calibration, consent handling or adversarial filesystem execution tested. Do not expose this function as a live API or accept untrusted registries. No claim of media detection effectiveness or ACAT qualification.

## E1 proposed adapter boundary
1. Human supplies lawful, public-safe or specifically consented media for declared purpose. Local-only initial processing. Record clip ID, actual SHA-256 of bytes, acquisition receipt/time, canonical source, version, clip range and claim ID; preserve original, derivative hashes and transformation chain. No private metadata in public records.
2. ffprobe/FFmpeg (candidate local tools) extract technical metadata, timestamps, keyframes, audio and discontinuity indicators. Record tool version and exact commands; compression, lighting, editing and detector error are alternate explanations. Detector observations never authenticate content.
3. C2PA adapter validates signed manifest/asset binding, trust chain and disclosed actions; record verification result and omissions, not inferred event truth. Missing credentials are UNKNOWN; valid signatures are not factual truth. Reverse keyframe tracing (InVID/other lawful search) identifies earlier appearances and common source roots; date/location context needs independent evidence. Preserve source licenses and minimize personal data.
4. Independent custodian verifies original recording/production history, event facts and claim-specific primary sources; distinguish independent capture vs derivative distribution, staging vs remote control vs autonomous action. Claims about mechanism and intent need separate proof. Use structured evidence references, root lineage and independently retained digests; no raw personal identifiers in public exports. Treat all captions and media as untrusted data.
5. Existing Witness/Unit Zero may explain derived public-safe findings through its approved interface after human consent; do not bypass existing allowlists. IOG receives proposed claim→source→clip→transformation→corroboration→correction projection (no writeback in E0). ACAT-R measures evidence discipline and false-ready rate, not truth score. AEO/GEO consumes human-reviewed evidence-bearing script, uncertainty and correction metadata. No self-authorized release.

Per-axis confusion matrices, false accusation on camera footage, synthetic misses, selective coverage/abstention, wrong-context rate, source/claim binding failures, review time, and reproducibility.
