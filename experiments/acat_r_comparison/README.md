# ACAT-R second existing runtime: GNER-E1 versus equal-workload unit tests

Issue #1081 · draft PR #1082 · **admission HOLD** · authority effect NONE.

This directory compares two ways of checking the *unchanged* GNER-E1 runtime
`tools/gner_verify_e1.py::reconcile` on the same 30 constructed cases with the same expected labels:
plain `unittest.assertEqual` assertions, and ACAT-R (predeclared P1 commitment, source and rubric
digests, isolated worker, P3 byte-identical replay, evidence classes, explicit non-authority).
On identical inputs and labels both methods flag the same four cases. ACAT-R adds provenance,
not detections.

## Files

| File | Role |
|------|------|
| `study.py` | Offline study. `--run-owned-offline [--out DIR]` runs pin check, rubric enforcement, the unchanged 10-case conventional suite, P1 commit, P1/P2/P3, equal-workload comparison and the oracle packet. `--worker` is the isolated subprocess entry. |
| `rubric_registry.json` | Every rubric digest ever declared. Revision 0 is the predeclared digest from the issue body (bytes unrecoverable). Revision 1 is the digest actually executed, labels unchanged, pending human acceptance. `study.py` runs nothing (exit 2, `RUBRIC_BLOCKED.json`) unless the computed digest equals the active revision **and** that revision is human-accepted with a named acceptor. |
| `evidence_classes.json` | Per-case class: CONTRACT_EXPLICIT (11), IMPLEMENTATION_DERIVED (15), PROPOSED_POLICY (4). Proposed-policy cases are reported separately and never counted as contract-derived defects. |
| `oracle/ORACLE_REVIEW_PACKET.md`, `oracle/oracle_packet.json` | Independent oracle decision packet (generated PENDING template): 30 rows with source reference, input hash, expected, observed, evidence class. Regenerated by every run; a test asserts the non-editable fields match the committed snapshot. **Do not record decisions here.** |
| `oracle/ADJUDICATION.json` | Where the referee records ACCEPT / REJECT / REVISE per case, with rationale, identity, reviewer kind and contract citation. Validated by `study.py`; `confirmed_defects` = disagreements ACCEPTed by a HUMAN reviewer. Merged output goes to `oracle_adjudicated.json` in the evidence dir. |
| `live_probe.py`, `live_probe_spec.json` | Human-invoked, read-only probe of the supported `verify_lead()` entry point against real run ids. Verifies the runtime blobs before import; hashes the exact bytes `verify_lead` consumed via a pass-through observer. Not run in CI. Credential comes from `GITHUB_TOKEN` and is never written anywhere. |
| `receipts/live_probe_receipts.json` | Sanitized receipts from the 2026-10-30 live probe, re-run 2 (13 probes, consumed-response hashes, pin verification, public run fields, verify_lead outcomes). |
| `receipts/report_local_reproduction.json`, `receipts/P1_COMMIT_local_reproduction.json` | Local reproduction of the offline study under rubric revision 1, made before the acceptance gate was added. Informational; re-execution is blocked until acceptance. |
| `HELD_OUT_PROTOCOL.md`, `held_out/MANIFEST_TEMPLATE.json`, `held_out/SEAL_RECORD_TEMPLATE.json` | Procedure for an independently authored, sealed held-out set; the seal record is an unhashed sidecar. No held-out set exists; status HOLD. |
| `../../tests/test_acat_r_gner_e1_study.py` | Harness regression tests (listed in `.tool-control/baseline_tests.yaml`). |

## Boundaries

- The three original files are pinned by Git blob and are never edited:
  `tools/gner_verify_e1.py` `8290c51c`, `tools/gner_notification_e0.py` `e8f893a3`,
  `tests/test_gner_verify_e1.py` `8517a93f`.
- Offline results use constructed canonical metadata. A `CANONICAL_VERIFIED` from `reconcile()` on a
  caller-supplied mapping is not authenticated GitHub evidence.
- Expected labels are investigator-proposed. `confirmed_defects` is 0 until a referee accepts a label
  with a contract citation. Changing a label requires appending a `rubric_registry.json` revision.
- Nothing here merges, deploys, admits, or grants authority.
