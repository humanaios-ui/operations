## Files

- **Decisions:** Collaboration choices logged for transparency
- **Ecosystem Map:** Trust relationships and channel routing

## Adding a New Collaborator

1. Create `collaborators/{name}.md` with profile template
2. Log in `collaborator-ops/decisions/` if this opens a new partnership
3. Update this README
4. Link to ecosystem map if new trust path established
