## CRM review process

1. Read the pinned source at the snapshot commit, not a mutable file link.
2. Distinguish historical assertions from verified current status.
3. Confirm the responsible human owner, relationship scope, consent, attribution and agreement state.
4. Store real contact details, financial terms and partner IP in approved private storage only.
5. Request explicit human review for changes to current status, any external outreach and publication.
6. Record new evidence and corrections without altering the pinned historical snapshot.
