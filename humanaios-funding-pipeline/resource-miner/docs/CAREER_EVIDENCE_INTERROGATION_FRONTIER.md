# Career Evidence Interrogation Frontier

**Experiment:** EXP-CAREER-EVIDENCE-001  
**Purpose:** Recover professional evidence that may be missing from the current resume without inventing or overstating experience.

## How to answer

For each question:

1. Answer in plain language. Do not try to make it sound like a resume.
2. If you know an exact number, give it.
3. If you only know an estimate, label it **ESTIMATE**.
4. If you do not remember, write **UNKNOWN**.
5. If evidence exists, note where: email, report, audit, dashboard, GitHub, policy, performance review, spreadsheet, publication, etc.
6. Separate what **you personally owned** from what the larger team or organization owned.

Recommended response notation:

```text
ANSWER:
EVIDENCE AVAILABLE:
MY OWNERSHIP / DECISION RIGHTS:
CONFIDENCE: HIGH | MEDIUM | LOW
NOTES:
```

## Priority 0 — Cross-project evidence recovery

These questions can update multiple Project Evidence Records at once.

### Q0.1 Budget / financial authority
Across HumanAIOS, hospital/laboratory leadership, and Waffle House, what budgets, P&L, cloud/API credits, purchasing limits, capital requests, contractor spend, software spend, or operating expenses did you directly plan, approve, control, or report?

### Q0.2 Vendor / contractor / supplier management
Which vendors, consultants, contractors, implementation partners, suppliers, service agreements, or external support teams did you personally coordinate or manage? What authority did you have over selection, escalation, renewal, purchasing, performance, or termination?

### Q0.3 Formal project controls
Which formal project-management artifacts have you actually used: milestones, work plans, project schedules, dependency maps, risk registers, issue logs, decision logs, change logs, status reports, steering committees, acceptance criteria, go-live checklists, retrospectives, or postmortems?

### Q0.4 Quantified outcomes
List any measurable outcomes you remember from any major project: defects prevented/corrected, audit findings closed, cost savings, revenue/P&L change, cycle-time reduction, staffing improvement, uptime, adoption, turnaround time, error rate, compliance rate, training completion, incident reduction, or delivery timing.

### Q0.5 People leadership
Beyond headcount, what people-management responsibilities did you personally perform: hiring, interviewing, onboarding, scheduling, coaching, performance reviews, disciplinary action, promotions, succession planning, competency assessment, retention work, or termination?

### Q0.6 Executive / governance interaction
Which executive teams, boards, medical directors, steering committees, regulators, accrediting bodies, state programs, researchers, or external partners did you report to or coordinate with? What decisions or recommendations were you responsible for bringing forward?

### Q0.7 Systems / platform inventory
List named systems you have implemented, administered, validated, integrated, migrated, or materially operated: EMR/EHR, LIS, middleware, analyzers, quality/risk systems, dashboards, cloud platforms, GitHub, automation tools, databases, model APIs, scheduling/POS/inventory systems, etc.

### Q0.8 Incident / corrective-action practice
Where have you personally led incident response, root-cause analysis, corrective action, CAPA-like work, escalation, rollback, recovery, or post-event review? What process did you use and what evidence remains?
