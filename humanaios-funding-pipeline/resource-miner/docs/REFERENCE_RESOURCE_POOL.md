# Reference Resource Pool

Human references are treated as consent-bearing resources, not as free-form contact records.

## Graph

```text
APPLICATION / GRANT
        ↓
REFERENCE REQUIREMENT
        ↓
REFERENCE RESOURCE
        ↓
EVIDENCE DOMAIN
        ↓
CONSENT
        ↓
AVAILABILITY
        ↓
AUTHORIZED USE
        ↓
REFERENCE OUTCOME
```

## Privacy boundary

The public repository may store only non-identifying metadata and opaque pointers. Names, email addresses, phone numbers, private relationship details, and reference communications do not belong in this repository.

```text
REFERENCE_RESOURCE != CONTACT_RECORD
CANDIDATE_REFERENCE != CONSENTED_REFERENCE
CONSENT_FOR_ONE_APPLICATION != GLOBAL_CONSENT
REFERENCE_AVAILABILITY != AUTHORIZATION_TO_CONTACT
```

The initial pool provides three empty slots covering:
- execution / judgment / leadership;
- research / quality rigor / technical depth;
- entrepreneurship / collaboration / execution.

Binding a real person requires a private contact record and explicit consent status.
