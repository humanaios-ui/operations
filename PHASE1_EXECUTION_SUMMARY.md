## Financials (Phase 1 Pilot)

### Revenue Model
```
Employer funds task: $500
├── Stripe processing: -$11 (2.2%)
├── Empirica coordination fee: -$25 (5%)
├── Worker receives: $465 (93% of employer funding)
└── Empirica operational cut (after Stripe): $14/task
```

### Pilot Projections (20-50 matches over 6 weeks)
```
Conservative (20 matches):
  Income: 20 × $14 = $280
  Expenses: Platform setup + verification bonuses (~$300)
  Net: -$20 (break-even)

Optimistic (50 matches):
  Income: 50 × $14 = $700
  Expenses: ~$300
  Net: +$400
```

### Scaling (If Phase 2 approved)
```
Phase 2 (200 matches/month):
  Income: 200 × $14 = $2,800
  Expenses: ~$500 (infrastructure + research)
  Monthly net: +$2,300 (+$27.6K/year)
  Sustainable operational model
```
