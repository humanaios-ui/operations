## Methodology

### How Amendments Are Selected

1. **Community submissions** across all platforms
2. **Moderation check** (relevance, civility, attribution)
3. **Quality scoring:**
   - Specificity: Exact text change vs. vague critique
   - Evidence: Supported by example or measurement
   - Rationale: Clear "why" statement
   - Attribution: Named contributor
   - Integration: Aligns with HumanAIOS practices
4. **Z1 aggregation:** Patterns identified, strongest selected
5. **Z1 candidate creation:** Formal block with rationale + falsifier
6. **Z2 ratification:** 48-hour window, ACCEPT/EDIT/REJECT
7. **Version release:** If accepted, merged into next version

### Falsifier Discipline

Each amendment includes a **falsifier**: "How would we know if this change failed?"

Examples:
- "Failed if [principle] is violated in >10% of observed deployments"
- "Failed if no independent audit exists 6 months post-deployment"
- "Failed if community signal drops by >50% when measuring principle adoption"

Falsifiers tracked in NF_LEDGER.jsonl for ongoing measurement.
