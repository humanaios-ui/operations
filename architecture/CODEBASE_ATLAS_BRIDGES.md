# Codebase Atlas · four read-only graph lenses (v0.1)

**Status:** Z1 candidate in PR #835. No admission, merge or approval effect.

The Codebase Atlas gains explicit, HEAD-pinned bridges into four *existing* Operations surfaces:

| Lens | Source of record | What the bridge shows | What it never claims |
|---|---|---|---|
| Evidence Graph | `EVIDENCE_GRAPH.json` | Evidence node labels matching unique tracked paths exactly | That a claim was tested or a runtime connection exists |
| Session Graph | `chat_graph/source/...v0.1.json` and historical hydration overlay | Source-ref context, exact path references and historical observation time | That old hydration reflects current HEAD or independent truth |
| SCVC | `tools/state_continuity_verification_v0_1.py`, VLR schema, trusted witness implementation | Source-pinned interface existence | Continuity verified or milestone achieved |
| Repository Coordinator | `REPOSITORY_COORDINATOR_POLICY.json`, Coordinator implementation | Declared control-plane path membership | Review approval, state-branch admission, authorization, merge rights |

## Outputs

Run `python architecture/codebase_atlas.py --out /tmp/humanaios-atlas`. This yields `atlas.json` with its `bridges` projection, separate `bridges.json`, `index.html` with a browsable cross-graph panel, and the existing Mermaid/Markdown outputs. Each view lists expected and present pinned sources; mappings require exact tracked paths or an unambiguous basename. Each source includes a SHA-256 hash and the same pinned Git commit. Unmatched files are not invented. Code and content come from `git show HEAD:<allowlisted path>`, not an untrusted worktree file or network response. The static dependency map remains independently generated.

## Invariants

- `GRAPH_IS_NOT_AUTHORITY`: bridge assertions are **observations**, never approvals.
- `SOURCE_BINDING_IS_NOT_CLAIM_PROOF`: an evidence node label is not test verification.
- `CHAT_MEMORY_IS_NOT_INDEPENDENT_EVIDENCE`: Session Graph nodes remain `CHAT_DERIVED`.
- `SCVC_CONTINUITY_NOT_ESTABLISHED`: no independent witness executes in the bridge.
- `COORDINATOR_STATE_NOT_READ`: the separate admission ledger and state branch are not read. The observer cannot emit an admission verdict.
- `NO_SELF_AUTHORIZATION`: authority_effect NONE, merge_authority false, can_authorize false and authenticated false.
- `TIME_ORTHOGONAL_TO_AUTHORITY`: historical overlay `observed_on` and historical commit SHA remain separate from Atlas HEAD; elapsed time creates no standing.
- `PRIVATE_ROOTS_NOT_HYDRATED`: no private ChatGPT/Drive/email source roots are opened or serialized.
