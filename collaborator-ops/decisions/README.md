## How to Add a Decision

1. **New collaboration choice:** Will it affect multiple parties or future work? Log it.
2. **Dispute or disagreement:** Collaborators disagree on approach? Log it with resolution process.
3. **Approval needed:** Decision requires sign-off from multiple parties? Create entry, track status.

**No need to log:**
- Day-to-day work decisions (those stay in project files)
- Internal HumanAIOS-only choices (those stay in project planning)
- Logistical details (scheduling, admin)

---

## Escalation

If a decision is disputed:
1. **Initial:** Parties discuss 1-1, try to reach agreement
2. **Second:** If unresolved, present to decision-maker (e.g., Carly for HumanAIOS questions)
3. **Third:** If still disputed, escalate to funder (e.g., Longview for grant-related) or mediator
