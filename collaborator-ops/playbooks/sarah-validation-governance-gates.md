## Seven Governance Decision Gates (From Framework)

The onboarding framework has 7 decision points. **This document flags which ones are still TBD and what we need from mesh-support to fill them in.**

---

### GATE #1: Approve Vetting

**When:** After we identify a candidate and vet for mesh-readiness (Stage 1)

**The Question:** 
- Is the vetting process sufficient?
- Does vetting need to be human-gated (ECO decision)?
- Or can it stay operational (internal team only)?

**What We're Assuming:**
- Operational (no ECO gate) — internal team reviews mesh-readiness and decides to proceed
- Unless: conflict-of-interest sensitivity or cross-org implications

**What We Need from David:**
1. [ ] Is this operational or ECO-gated?
2. [ ] If operational: Who approves? (e.g., "Carly + David + [team]"?)
3. [ ] If gated: What's the approval timeline? (1 day? 1 week?)
4. [ ] Are there conflict checks we're missing? (e.g., call a reference?)

**For Sarah's Dry-Run:**
- Assume operational — David & Carly confirm together during walkthrough call
- Testing question: "Does this gate feel in the right place?"

---

### GATE #2: Proceed with Outreach

**When:** After vetting is approved, before sending invitation (Stage 2)

**The Question:**
- Once vetting is done, is there ANOTHER gate before we send the invite?
- Or do we go straight to outreach?

**What We're Assuming:**
- For internal candidates (like Sarah): No second gate — proceed to outreach
- For external candidates: Might need a second gate (e.g., "Is this a cross-org candidate? Does it need ECO routing?")

**What We Need from David:**
1. [ ] For internal candidates: Do we need Gate #2, or go straight to outreach?
2. [ ] For external candidates: What triggers Gate #2? (Cross-org? High-commitment level?)
3. [ ] If gated: Who decides? Approval timeline?
4. [ ] Do we need an SER (Shared Epistemic Record) for any collaboration levels?

**For Sarah's Dry-Run:**
- Assume no second gate — proceed straight to outreach after Stage 1
- Testing question: "Should there be another gate here? Why/why not?"

### GATE #3: Create Engagement Record

**When:** After a candidate accepts outreach & clarification is resolved (Stage 3)

**The Question:**
- When we actually start collaborating with someone, do we need to formally create an "engagement record"?
- Is this operational or gated?

**What We're Assuming:**
- Operational — Carly creates engagement record + enters into collaborator-ops system
- Duration: 3-6 months (default, customizable)
- Success metrics: Logged per-collaboration

**What We Need from David:**
1. [ ] Should engagement records be created for all collaborators, or only certain levels?
2. [ ] Do we need a specific template or schema?
3. [ ] Who's responsible for maintaining the record?
4. [ ] Does this need ECO gating? (Probably not for Advisor level)

**For Sarah's Dry-Run:**
- Skip (validation ends after Stage 2)
- Testing question: "Should we be thinking about engagement records earlier in the process?"

### GATE #4: Escalate Mid-Collaboration

**When:** During active collaboration, if we want to promote an Advisor to Co-I (or similar)

**The Question:**
- If Sarah starts as Advisor and we want to escalate her to Co-Investigator, is that a decision gate?
- Operational or ECO-gated?

**What We're Assuming:**
- ECO-gated (because it's a material change to commitment/authority)
- Approval: David or human decision-maker
- Timeline: Flexible (don't need to rush)

**What We Need from David:**
1. [ ] Is mid-collaboration escalation ECO-gated?
2. [ ] What's the decision authority? (David? Carly + David?)
3. [ ] Do we need a formal proposal, or informal discussion?
4. [ ] Timeline expectations? (1 week? 1 month decision window?)

**For Sarah's Dry-Run:**
- Skip (not relevant until later)
- Testing question: "Should we mention this possibility to candidates upfront?"

### GATE #5: Close Collaboration

**When:** 3-month checkpoint or project completion; time to decide "continue or close"

**The Question:**
- Closing an Advisor relationship — is this operational or gated?
- Do we need anyone's approval to say "thanks, we're good now"?

**What We're Assuming:**
- Operational (Carly + collaborator mutually agree to close)
- Unless: Cross-org or special governance needs

**What We Need from David:**
1. [ ] Is closing operational or gated?
2. [ ] Do we need to follow a specific process? (e.g., 30-day notice, retro call?)
3. [ ] Anything special for cross-org closures?

**For Sarah's Dry-Run:**
- Skip (validation ends after Stage 2)
- Testing question: "How do we gracefully close a collaboration?"

### GATE #6: Escalate Collaboration Publicly

**When:** If we want to credit a collaborator publicly or publish findings from collaboration

**The Question:**

**What We're Assuming:**

- For Sarah (test-candidate): Assume no publication during validation
- For real collaborators: Get per-artifact consent

**What We Need from David:**
1. [ ] How do we handle publication consent? (Per-project? Per-document? Blanket?)
2. [ ] Do we need a gate for this, or handle it in the engagement record?
3. [ ] P-ANON requirements for cross-org collaborators?

**For Sarah's Dry-Run:**
- Skip (validation is internal only)
- Testing question: "Should we mention publication policies to candidates upfront?"
